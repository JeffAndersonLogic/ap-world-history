How to get the Canvas file
  1. In Canvas, open the quiz (New Quizzes) and choose Reports.
  2. Choose Student Analysis, generate the report, and choose Export CSV.
  3. Drop the downloaded file here. You do not need to open or change it first.
Where the question map comes from, and why it is a separate file
  • The map lists each question's learning target and its correct answer, so it is the answer key. It is never put on this website, which anyone can open.
  • It is built from the test's own source file and shared privately with the teachers who give that test. Keep it off student-shared drives.
  • The page matches each Canvas question to the map by the answers students chose, so it works with your own copy of the quiz even if Canvas shuffled the order.
