    Read it with

    Paste each batch into a new chat and paste the reply back here. The chat gets the question, the criteria, the rubric and the answers, numbered: no names, no class. Each batch is checked first for anything a student wrote that could identify them, and you decide what to remove. Every rating it sends back is checked before it shows, and one that quotes words the student did not write shows as Can't tell.

    1. Press Copy batch.
    2. Open a new chat, one for each batch, and paste.
    3. When the reply finishes, press the copy button under it.
    4. Open Paste the reply on the same batch, paste, and press Read this reply.
