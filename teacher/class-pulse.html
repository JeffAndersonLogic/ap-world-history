    Read everything waiting

    1. Copy.
    2. Paste it into the Class Pulse Reader, a private page in your Claude for Teachers account. It reads the answers one at a time and checks its own work. Open the Reader
    3. Paste the Reader's result here.

    What is copied is the question, the criteria, the rubric and the numbered answers: no names, no class, no account. Anything a student wrote that could identify them is flagged above, and you decide what to remove before Copy unlocks. Every reading that comes back is checked again here before it shows.

    If Copy does not work on this device

    Select all of the text below and copy it yourself.

    Or read it batch by batch in a chat

    Paste each batch into a new chat in that service and paste the reply back here. Both services get the same text, and every reading records which one proposed it. The chat gets the question, the criteria, the rubric and the answers, numbered: no names, no class. Each batch is checked first for anything a student wrote that could identify them, and you decide what to remove. Every rating it sends back is checked before it shows, and one that quotes words the student did not write shows as Can't tell.

    1. Press Copy batch.
    2. Open a new chat, one for each batch, and paste.
    3. When the reply finishes, press the copy button under it.
    4. Open Paste the reply on the same batch, paste, and press Read this reply.
