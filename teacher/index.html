Live class analysis from Google Forms, all units and topics
Connection

Enter your Web App URL and access token

The Teacher Hub reads your Google Sheet through the BeHistorical Apps Script web app. Paste its URL and the access token you generated from the Sheet's BeHistorical menu. Both are stored in this browser only, so you enter them once per device.

Don't have these yet?

Open your Google Form response Sheet, then:

  1. Extensions → Apps Script, and paste in tools/teacher-hub/google-apps-script/Code.gs.
  2. Reload the Sheet, then run BeHistorical → Create/Repair Teacher Hub Tabs.
  3. Run BeHistorical → Create Teacher Hub Access Token and copy the token.
  4. In Apps Script, Deploy → New deployment → Web app, with Execute as: Me and Who has access: Anyone. Copy the /exec URL.
Why "Anyone" is required: this page is static, so its request cannot carry your Google login. Any other access setting makes the endpoint unreachable from here. That is also why the endpoint never returns student names or response text. It sends counts, patterns, and numbered labels; the names stay in your Sheet on the TeacherHub_StudentFlags tab, matched to the same numbers.
