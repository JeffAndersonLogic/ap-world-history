# Topic 3.2 Claim Ledger

Started 2026-10-05 in Phase 3, before the story gate, so the story Jeff approves has already
been checked. One row per **material** claim (see the build-topic skill, Phase 9A). A claim that
repeats across surfaces is one row listing every place it appears. Rows for the deck, the
rewritten reading and the other surfaces are added as those surfaces are built.

Status is exactly one of VERIFIED, NARROWED, REMOVED, NEEDS JEFF.

**The CED decides scope; scholarship decides truth.** CED wording is quoted from
`scripts/lib/ced-unit3-contract.js` and the lesson's `collegeBoardKeyConcepts`; it is cited
only for what is required, never as evidence that something happened.
