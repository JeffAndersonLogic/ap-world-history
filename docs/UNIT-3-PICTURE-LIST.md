# Unit 3 picture list, Topics 3.2 to 3.4

**Status: shopping list for Jeff, 2026-10-05. Not yet approved for any slide.** Written before
the 3.2 to 3.4 stories were drafted, from the approved `docs/UNIT-3-STORY-MAP.md`, so each
topic's story gate may drop or add rows. Upload chosen files to `assets/images/topics/3-X/`;
the build wires them in with the **presentation-images** skill.

Every object below was checked against a museum, library or UNESCO record on 2026-10-05, with
the source in the last column. **None of these is a Commons filename.** The build still runs
each chosen file through `scripts/source-evidence-images.js --describe` (or the
presentation-images checks for an upload) and reads what the file really is against its
caption.

Already in the topics' Evidence Labs, so not repeated here: Akbar's court (Akbarnama), Topkapı
Palace, Shah Abbas I, the Qianlong Emperor, Martin Luther (Cranach circle), the Chaldiran
miniature from the Selimname (c. 1524), Guru Nanak (19th-century portrait), Süleyman, Peter the
Great (the Mardefeld miniature: Mardefeld was a painter as well as Prussia's envoy, so that
credit is correct), and two secondary maps.

peasant to treasury) than forced onto a weak picture.

## 3.4: Every empire had the same jobs

**No new pictures are needed.** The story map says 3.4 introduces no new content, so the deck
reuses 3.1 to 3.3's verified objects, set side by side. Two things worth having:

1. **One matched set of ruler images**, one per empire being compared, so a comparison slide
   compares rulers rather than painting styles.
2. **The four-empire map** made for 3.1, reused, so students compare on a map they have
   already seen.

Before choosing, the build checks the CED's own list of empires for 3.4. The current Evidence
Lab frames five, including Russia.
