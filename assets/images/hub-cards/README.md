# Hub card crops

Trimmed copies of pictures used as the photograph layer on unit hub topic cards
(`img.card-photo` in `unit-N/index.html`). A copy is made only when the original
carries a paper margin or printed border that would show as a frame on the card.
The originals stay untouched in their own folders, because the slide decks use them.
