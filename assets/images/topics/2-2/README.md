# Topic 2.2 Visual Assets

Upload approved Topic 2.2 presentation images here.

Recommended filename pattern:

`2-2-type-subject-description.ext`

Examples:
- `2-2-map-mongol-expansion.png`
- `2-2-reconstruction-mounted-archers-ai.webp`
- `2-2-reconstruction-yam-relay-ai.webp`
- `2-2-reconstruction-protected-caravan-ai.webp`

Use descriptive filenames. Keep source/license information in a manifest or source note rather than in the filename.
