# Topic 2.6 Visual Upgrade Targets

The Topic 2.6 Teaching OS is built from the ninth-grade story spine: trade accidentally connected ecosystems. It is teachable with stable local instructional maps plus Wikimedia fallback images. For maximum visual impact, replace fallback visuals only after these assets are added here.

## Highest-value uploads

1. `2.6 - Biological Connectivity Hero.jpg`
   - 16:9 or wider.
   - A visually strong Afro-Eurasian network scene or map-composite showing trade routes as biological corridors.
   - Purpose: establish the core thesis that trade accidentally connected ecosystems.

2. `2.6 - Crop Diffusion Map.jpg` or `.svg`
   - Highest priority.
   - A clean classroom-readable map with only three movements: bananas into Africa, new rice varieties in East Asia, and citrus into the Mediterranean.
   - Purpose: replace the current functional box-and-arrow crop map with a stronger geographic visual.

3. `2.6 - Crop Diffusion Triptych.jpg`
   - Three panels: banana cultivation, rice cultivation, Mediterranean citrus.
   - Purpose: keep the crop branch visually equal to the plague branch so 2.6 does not become only a Black Death lesson.

4. `2.6 - Black Death Human Consequence.jpg`
   - Prefer a medieval manuscript or period-adjacent visual of plague mortality, burials, or mass death.
   - Avoid later plague-doctor costume imagery because it visually belongs to a later period and will mislead students.
   - Purpose: make demographic catastrophe visible after the map establishes route movement.

5. `2.6 - Same Network Opposite Effects.jpg`
   - A split composition: crop diffusion on one side, pathogen diffusion on the other, with connectivity at the center.
   - Purpose: support the key synthesis slide: same cause, opposite biological effects.

## Visual standard

- Prefer maps, manuscript art, agricultural imagery, and artifact/source visuals.
- Do not use generic stock plague imagery.
- Keep text-safe negative space where possible.
- Repo-local assets are preferred for production stability.
- If an AI reconstruction is ever used, label it clearly as historical reconstruction / AI generated.
