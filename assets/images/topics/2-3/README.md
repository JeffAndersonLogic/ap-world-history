# Topic 2.3 Visual Assets

Upload approved Topic 2.3 presentation images here.

Recommended filename pattern:

`2-3-type-subject-description.ext`

Examples:
- `2-3-map-indian-ocean-trade-network.png`
- `2-3-place-calicut-port.jpg`
- `2-3-reconstruction-dhow-merchant-vessel-ai.webp`

Use descriptive filenames. Keep source/license information in a manifest or source note rather than in the filename.
