# Topic 2.1 Visual Assets

Upload approved Topic 2.1 presentation images here.

Recommended filename pattern:

`2-1-type-subject-description.ext`

Examples:
- `2-1-map-silk-roads-network-1200-1450.png`
- `2-1-place-samarkand-registan.jpg`
- `2-1-reconstruction-caravanserai-interior-ai.webp`

Use descriptive filenames. Keep source/license information in a manifest or source note rather than in the filename.
