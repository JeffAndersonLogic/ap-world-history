- 50 multiple-choice questions, 100 points, 55 minutes (from the archived QTI metadata).
- `BeHistorical_Era_2_Exam_V2_1_Canvas_QTI.zip` is the original Canvas import package, preserved byte-for-byte.
- `qti/behistorical_era2_v2/behistorical_era2_v2.xml` contains the questions, stimuli, choices, scoring keys, and feedback in readable XML. Claude and other repository agents should start here to inspect the assessment.

- `qti/imsmanifest.xml` is the original package manifest.

The internal `behistorical_era2_v2` identifiers are inherited from the original package; the assessment title and archive filename identify Version 2.1.
