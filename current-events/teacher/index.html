Teacher Hub

Pacing, the live class data, and the coach. Three links and a calendar, nothing to keep updated by hand.

The data layer

Form to responses to Claude to coach.

Every capture point writes to the class form with the lesson, step, and prompt ID already filled in, so responses arrive pre-sorted. Lesson 1 carries seven of them. Read them, hand the export to Claude for patterns and misconceptions, then load what you learn into the coach.

Step 1

Class responses

The live response summary for every checkpoint submitted across all periods.
Step 2

Claude analysis

Export the sheet and ask for the patterns: which links students cannot justify, where causation slides into resemblance, who is stuck.

Step 3

Reverse History Coach

The MagicSchool classroom students reach from every lesson page. Feed it what the analysis found.
